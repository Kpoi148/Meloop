- [`DB_MIGRATION_PLAN.md`](DB_MIGRATION_PLAN.md): schema SQLite journal v1, trường dữ liệu, ràng buộc, migration và backup mapping.

- [`FE_SHARED_UI.md`](FE_SHARED_UI.md): task 10, theme Tempo, thành phần và ví dụ cho Wei.
- [`FE_UI_VALIDATION.md`](FE_UI_VALIDATION.md): kết quả kiểm chứng UI của lần bàn giao.
- [`FE_RIVERPOD.md`](FE_RIVERPOD.md): quản lý trạng thái frontend, cấp dependency qua app và nối backend sau.
- [`FE_INSTRUMENT_PROFILES.md`](FE_INSTRUMENT_PROFILES.md): task 14, luồng hồ sơ nhạc cụ và bản xem thử FE.
- [`FE_PRIVACY_SUPPORT.md`](FE_PRIVACY_SUPPORT.md): task 44, màn riêng tư/hỗ trợ, bản nháp email và cấu hình PM còn thiếu.
- [`FE_PITCH_UI.md`](FE_PITCH_UI.md): task 29 / UC-09, giao diện cao độ và bản xem thử FE.
- [`BE_PITCH_SERVICE.md`](BE_PITCH_SERVICE.md): hướng dẫn backend nối service cao độ, trạng thái, quyền micro, Start/Stop và kiểm tra Android thật.
