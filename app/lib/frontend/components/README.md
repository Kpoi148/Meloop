# Shared UI Components

Kho thành phần giao diện dùng chung trên toàn ứng dụng để đảm bảo đồng bộ thiết kế và tránh viết lặp lại:

- `buttons/`: nút bấm, chống bấm đúp và trạng thái đang lưu.
- `inputs/`: ô nhập liệu, thanh tìm kiếm, nhãn bắt buộc/tùy chọn và hiển thị lỗi tại trường.
- `selections/`: thành phần lựa chọn (chip, dropdown, checkbox, radio, switch).
- `dialogs/`: hộp thoại xác nhận, cảnh báo, bottom sheet và thông báo dùng chung.
- `navigation/`: thanh điều hướng trên/dưới và tab.
- `feedback/`: trạng thái đang tải, trống và lỗi.
- `layout/`: khung bố cục chuẩn hóa safe area, chống tràn khi phóng chữ hoặc mở bàn phím.
