# Theme

Định nghĩa `ThemeData` dùng chung cho toàn ứng dụng Meloop, kết nối các design token về màu sắc, kiểu chữ, khoảng cách, bo góc và kích thước icon.

- `tokens/`: chứa các thông số thiết kế gốc đã chuẩn hóa từ Tempo.

`MeloopTheme.light` dùng Be Vietnam Pro cục bộ và giá trị sau lớp ghi đè `fidelity.css`. Nguồn duy nhất là `tokens/tempo_tokens.dart`; xem [hướng dẫn FE](../../../../docs/FE_SHARED_UI.md).
